For sites using pspdfkit to prevent PDF downloads. This script
fetches each page as an image and bundles those into a PDF.

To be used as a bookmarklet or similar. If nothing happens
when running this, try reloading the page, otherwise the
next.js data may be incomplete.

## How to use
Create a new bookmark. In the URL field, enter the following text. Then navigate to the page where you want to download the PDF, and click the bookmark.

Alternatively, instead of creating a bookmark, you can navigate to the page where you want to download the PDF, open the browser console with F12 and paste the contents of [downloader.js](downloader.js).

## Where to use
I think it works for `next.js`+`pspdfkit` websites. May have
something to do with React, not sure, it looks for a
`#__NEXT_DATA__` block. These websites are known to be supported:
- Boom Digitaal: https://e-book.boomdigitaal.nl/
- probably more... If the PDF viewer looks like this,
give it a try, and let me know whether it works by creating
an issue here on github.
